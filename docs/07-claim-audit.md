# 거짓 약속 감사 — 2026-08-16

화면 문구가 약속하는 동작이 실제로 되는지 전수 대조한 기록.

## 왜 했나

사용자가 직접 발견했다. 첫 실행 안내가 "갤러리에서 기프티콘을 찾아 등록"을 1번
항목으로 내세웠는데, 웹 체험판에는 ML Kit이 없어 그 기능이 흐려져 있었다.
등록 화면 **안쪽**에는 안내가 있었지만 거기까지 가야 알 수 있었다.

코드가 틀린 게 아니었다. **문구를 새로 쓰면서** 생긴 문제다. 그래서 같은 유형이
또 있는지 찾기로 했다.

## 방법

| 단계 | 역할 |
|---|---|
| 감사관 A | 화면 코드(`lib/**/presentation/`)의 한글 문자열 전수 대조 |
| 감사관 B | 문서·설정·알림·백업·선물 계층 |
| 수퍼바이저 | 각 후보를 **반증 시도**. 실패한 것만 확정 |
| 후속 감사 | `TASKS.md`의 `[x]` 항목 전수 대조 |

에이전트 정의는 `.claude/agents/capability-claim-auditor.md`,
`.claude/agents/claim-audit-supervisor.md`.

수퍼바이저는 감사관 주장 1건을 기각했고(첫 실행 안내의 알림 항목은 바로 아래
고지가 덮고 있었다) 3건을 새로 찾았다.

## 확정된 것

### 기능이 없는데 있다고 말한 것

| 항목 | 실체 |
|---|---|
| 앱 잠금 | 스위치를 켤 때 시험 인증 1회. 앱 실행 시 인증 게이트가 코드에 없었다 |
| AI 보정 | `LlmAssist` 인스턴스화 코드 0건. 켜도 꺼도 동작이 같았다 |
| 만료 알림 | `reschedule()` 호출부가 설정 화면 한 곳. 켠 **뒤에** 등록한 쿠폰은 영영 알림이 없었다 |
| 쿠폰 삭제 | `ImageStore.remove()` 호출부 0건. 이미지가 접근 불가 상태로 기기에 남았다 |
| 웹 선물 공유 | `share_plus` 웹은 성공해도 `unavailable`. 바코드는 전달됐는데 쿠폰은 사용 가능으로 남았다 |
| 웹 백업 | 파일은 내려가는데 성공·실패 안내가 둘 다 없었다 |

### 환경 분기를 빠뜨린 문구

등록 폼 유효기간 helper(웹의 유일한 등록 경로), 첫 실행 안내 2번 걸음(밝기),
사용 방법 2번 걸음·알림 팁, 설정 스위치(눌러야 거절), 웹 앱잠금 거절 문구.

`BrightnessControl.isSupported`는 **정의만 있고 읽는 화면이 하나도 없었다.**
분기할 수단이 없으면 문구는 반드시 거짓이 된다.

### 정직하지 않은 스텁

`app_lock_stub.authenticate()`가 `true`를, `notification_service_stub.reschedule()`이
0이 아닌 건수를 돌려줬다. 둘 다 그 위에 게이트를 세우는 순간 통과해 버리는
함정이었다.

## 결정

- **앱 잠금**: 1.0에서 제외. 스위치·`local_auth`·`NSFaceIDUsageDescription`·
  `USE_BIOMETRIC`·방침 문단까지 제거. 1.1로.
- **AI 보정**: 제거. 스위치·`llm_assist.dart`·`http` 의존성·방침 §5 삭제.
  이제 "네트워크 전송 없음"이 코드와 문서 양쪽에서 참이다.

## 재발 방지

`test/widget/capability_claim_test.dart`가 소스를 직접 검사한다. 환경 의존
기능을 약속하는 문구가 있는 화면은 해당 capability를 반드시 읽어야 하고,
스텁은 성공을 흉내 내면 안 된다.

가드가 실제로 잡는지 역검증했다 — 밝기 분기를 상수로 되돌리니 실패했고,
원복하니 통과했다.

## 남은 한계

**"발생확률 0"이라고 말할 수 없다.**

- 감사는 전부 **정적 분석**이다. 실기기 검증 이력이 여전히 없다.
- 가드는 문자열 패턴 매칭이라, 등록하지 않은 표현으로 새 약속을 쓰면 못 잡는다.
  새 플랫폼 의존 기능이 생기면 목록을 손으로 늘려야 한다.
- `T-146` iOS 수출 규정 자기분류(`ITSAppUsesNonExemptEncryption=false` vs
  AES-256-GCM)는 법무 판단 영역이라 미결.
