# 모바일 쿠폰(기프티콘) 관리 앱 — 시장 리서치

조사일: 2026-07-31 · 대상 시장: 한국 기프티콘

---

## 1. 시장 지형

한국 "모바일 쿠폰" 앱은 성격이 뚜렷하게 3개 층으로 갈린다.

| 층 | 대표 앱 | 성격 | 관리 기능 수준 |
|---|---|---|---|
| 발행사 지갑 | 기프티콘(SK플래닛), 카카오톡 선물함 | 자사 발행분 보관 | 자사 콘만. 타사 콘 관리 불가 |
| 거래 마켓 | 니콘내콘, 기프티스타 | 할인 매입·판매 | 매매가 본질. 보관·알림은 부가 |
| 순수 관리 앱 | 기프티지갑, Gifcady, 기프티함, 기프티월렛, 꽉꽉, 잊지마쿠폰 | 통합 보관·알림 | 이 층에서 경쟁 |

핵심 구조적 문제: **발행사 지갑은 벽으로 둘러싸인 정원(walled garden)이다.** SK플래닛 기프티콘 앱은 "기프티콘이라는 회사를 통해 오는 콘만 관리 가능"하다. 사용자의 쿠폰은 실제로는 카카오톡·문자·이메일·각종 이벤트로 흩어져 들어온다. 그래서 통합 관리 앱 수요가 계속 발생하지만, 이 층은 지금 리더가 비어 있다.

### 결정적 사건 — 스윗비콘 서비스 종료 (2025-05-08)

커뮤니티에서 압도적으로 사랑받던 통합 관리 앱 **스윗비콘**이 2025년 5월 8일 종료했다. 사용자들이 꼽은 스윗비콘의 강점은 셋이다.

1. **캡처하면 바로 등록** — "기프티콘 캡처하면 바로 등록되는 기능이 꿀"
2. **광고 없음**
3. **심플한 디자인**

종료 이후 커뮤니티는 대체 앱을 찾지 못하고 있다. "스윗비콘을 완벽히 대체할 수 있는 앱을 찾기 어렵다"는 반응이 지배적이며, 클리앙·더쿠·뽐뿌·알구몬에 지금도 추천 요청 글이 반복 게시된다. **명확하게 비어 있는 자리이고, 이 앱은 그 자리를 노린다.**

## 2. 경쟁 앱별 분석

### 기프티지갑 (com.mrgu.giftwallet)
- **강점**: AI 스캐너로 이미지 속 유효기간 1초 추출. D-7/D-3/당일 알림. 금액권 잔액 관리 지원.
- **약점**: 알림 시점이 고정에 가깝고 사용자 리듬(주말에만 카페 감)을 반영하지 않음. 사용 맥락(매장 근처) 연결 없음.

### Gifcady (com.gifcady)
- **강점**: 만료일 알림 + 클라우드 백업.
- **약점**: 클라우드 백업이 기본 경로 → 바코드 이미지가 서버로 나간다. 후술할 보안 이슈와 정면 충돌.

### 기프티함
- **강점**: 자동 텍스트 인식으로 유효기간 자동 정리.
- **약점**: 인식 정확도에 대한 사용자 신뢰가 낮고, 실패 시 수동 보정 UX가 번거롭다는 반응.

### 오피스콘
- **강점**: 문자·카톡에 흩어진 쿠폰을 OCR로 한곳에 모음. B2B(임직원 선물) 발송에 강점.
- **약점**: B2B 발송이 본체라 개인 관리 UX는 부차적.

### 니콘내콘 / 기프티스타 (거래 마켓)
- **강점**: 할인 구매, 안 쓸 쿠폰 현금화. 검수·환불 보장.
- **약점**: 관리 앱이 아니다. 보관 중인 쿠폰의 만료 관리는 사실상 방치.

### 삼성월렛 / Google Keep (대체 수단)
- 사용자들이 실제로 쓰는 우회 경로. Keep은 "받는 족족 저장"은 되지만 알림을 **수동으로** 걸어야 하고, 삼성월렛은 쿠폰 등록은 되지만 유효기간 알림이 없다.
- 시사점: **사람들은 관리 앱이 없어서 메모 앱을 쓰고 있다.** 진입 장벽이 낮다는 뜻이다.

## 3. 리뷰·커뮤니티에서 반복되는 불만 (Pain Points)

우선순위는 언급 빈도와 손실 크기(돈이 실제로 사라지는가) 기준으로 매겼다.

| # | 불만 | 근거 | 손실 |
|---|---|---|---|
| P1 | **유효기간을 놓쳐 소멸** | "이벤트로 받은 기프티콘을 유효기간 내에 못 쓰는 경우가 많다" | 직접적 금전 손실 |
| P2 | **뭘 썼는지 모름** | "여러 개 있을 때 사용완료 버튼을 다 누르지 않으면 뭘 썼는지 안 썼는지 모르겠다" | 중복 방문·재확인 비용 |
| P3 | **금액권 잔액 추적 불가** | "기프티콘 사용여부 & 잔액확인 앱 있으면 좋겠다" (클리앙) | 잔액 유실 |
| P4 | **바코드 도용 위험** | 갤러리·중고거래에 노출된 바코드가 밝기 조절만으로 복원되어 도용. 발행사는 "보상 힘들다" 입장 | 전액 손실 + 보상 불가 |
| P5 | **OCR 부정확 / 수동 입력** | 인식 실패 시 전부 손으로 입력해야 함 | 이탈의 주원인 |
| P6 | **광고 과다** | 스윗비콘이 사랑받은 이유가 "광고 없음"이었다는 점이 반증 | 이탈 |
| P7 | **서비스 종료 = 데이터 증발** | 스윗비콘 종료 시 "저장된 기프티콘을 사용할 수 없게 됨" | 신뢰 붕괴 |
| P8 | **발행사별 분산** | 자사 콘만 지원하는 지갑들 | 통합 실패 |

P4와 P7이 특히 중요하다. 둘 다 **"이 앱을 믿고 내 돈을 맡길 수 있는가"** 라는 질문이고, 현재 어떤 경쟁 앱도 이걸 정면으로 답하지 않는다.

## 4. 니치 포지셔닝

### 한 줄 정의

> **갤러리에 잠들어 있는 기프티콘을 자동으로 찾아내서, 만료 전에 반드시 쓰게 만드는 앱. 사진은 폰 밖으로 절대 나가지 않는다.**

### 세 개의 차별점

**① 온디바이스 전용 (Local-only by default)**
- OCR, 바코드 인식, 저장, 알림 전부 기기 안에서 처리. 쿠폰 이미지와 바코드 번호는 서버로 전송하지 않는다.
- P4(도용)와 P7(서비스 종료 시 데이터 증발)을 동시에 해결한다. 서버가 없으니 서버가 죽어도 내 쿠폰은 살아 있다.
- 백업은 **사용자가 명시적으로 켤 때만**, 사용자 소유 클라우드(iCloud/Google Drive)에 암호화해서.
- 경쟁 앱이 클라우드 동기화를 세일즈 포인트로 삼는 것과 정확히 반대 방향. 이게 니치다.

**② 잔액이 있는 쿠폰을 제대로 다룬다**
- 한국 기프티콘의 큰 축인 **금액권**(스타벅스 3만원권 등)은 부분 사용이 일반적인데, 거의 모든 앱이 "사용/미사용" 이진 상태로만 다룬다.
- 사용 화면에서 나가면 바로 "얼마 쓰셨어요?"를 묻고 잔액을 차감. 사용 이력이 쌓인다. P2·P3 동시 해결.

**③ 쓰게 만드는 알림 (Context, not calendar)**
- D-7 알림은 이미 다 한다. 차별점은 **맥락**이다.
  - 위치: 스타벅스 반경 진입 → "여기서 쓸 수 있는 쿠폰 2장 (13,000원)"
  - 리듬: 사용자가 실제로 쿠폰을 쓰는 요일·시간대를 학습해 그 시점에 알림
  - 묶음: 만료 임박 쿠폰을 주간 1회 다이제스트로 (알림 피로 방지)
- P1을 "알려주기"가 아니라 "쓰게 하기"로 재정의.

### 타깃 사용자

- **1차**: 스윗비콘 난민 — 이미 통합 관리 습관이 있고, 광고 없는 심플한 앱에 돈을 낼 의향이 있다. 커뮤니티에 모여 있어 도달이 쉽다.
- **2차**: 카톡 선물을 자주 받는 20~30대 직장인 — 쿠폰이 쌓이는데 관리 수단이 Google Keep 수준.
- **3차**: 가족 단위 — 부모가 받은 쿠폰을 자녀가 쓰는 등 공유 수요.

### 하지 않을 것 (Non-goals)

- 쿠폰 매매/현금화 — 니콘내콘·기프티스타의 영역. 규제·정산 부담이 크고 니치를 흐린다.
- 발행사 API 연동 — 제휴 없이는 불가하고, 통합 관리라는 가치와 충돌한다.
- 광고 — 포지셔닝의 근간을 무너뜨린다.

### 수익 모델

무료로 전 기능 사용 가능, **Pro(1회 결제 또는 연 구독)** 로 확장.

| 무료 | Pro |
|---|---|
| 쿠폰 무제한 저장 | 암호화 백업/복원 |
| OCR 자동 인식 | 위치 기반 알림 |
| 만료 알림 | 가족 공유 |
| 금액권 잔액 관리 | 사용 통계·리포트 |
| 광고 없음 | 홈 위젯 |

"무료도 광고가 없다"가 핵심 신뢰 장치다.

## 5. MVP 기능 범위 (출시 1.0)

사용자가 말한 4개 축 — 인식 / 저장 / 관리 / 선물 — 으로 정리한다.

### 인식
- 갤러리에서 이미지 선택 → 온디바이스 OCR(한글) + 바코드 스캔 → 브랜드·상품명·유효기간·바코드·금액 자동 추출
- **갤러리 자동 스캔**: 최근 스크린샷에서 기프티콘으로 보이는 이미지를 찾아 일괄 등록 제안 (스윗비콘의 킬러 기능 재현·강화)
- 인식 실패 시 즉시 수동 보정 가능한 폼 (실패를 막다른 길로 만들지 않는다)

### 저장
- 로컬 DB(SQLite). 이미지도 앱 샌드박스 내 저장
- 브랜드 자동 분류, 카테고리, 메모, 태그
- 앱 잠금 (생체 인증) — 1.1로 연기

### 관리
- 보관함: 만료 임박순 / 브랜드별 / 카테고리별
- 만료 알림: D-30 / D-7 / D-3 / D-1 (같은 날 여러 장이면 하나로 묶음)
- 사용 화면: 바코드 확대 + 화면 밝기 자동 최대 + 나갈 때 사용 확인
- 금액권 잔액 차감 및 사용 이력
- 사용완료 / 만료 / 보관 상태 관리

### 선물
- 쿠폰 재선물: 이미지 + 정보를 카톡·메시지로 전달, 전달 즉시 내 보관함에서 "선물함" 상태로 이동
- 가족 공유: 같은 쿠폰을 여러 기기에서 조회, 한쪽이 쓰면 반대쪽에도 반영
