# 개인정보처리방침

**쿠폰다이어리 (Coupon Diary)**

시행일: 2026년 8월 1일 · 버전 1.0

> 이 문서는 웹에 게시한 뒤 그 URL을 App Store Connect와 Google Play Console에
> 등록해야 한다 (두 스토어 모두 필수). 사업자명·연락처는 실제 값으로 채운 뒤 게시한다.

---

## 요약

**쿠폰다이어리는 어떤 개인정보도 수집하지 않습니다.**

회원가입이 없고, 서버가 없으며, 앱이 만든 데이터는 전부 사용자 기기 안에만 저장됩니다.
쿠폰 이미지와 바코드 번호는 어떤 경우에도 외부로 전송되지 않습니다.

---

## 1. 수집하는 개인정보

없습니다.

이 앱은 이름, 이메일, 전화번호, 위치, 광고 식별자, 기기 식별자를 포함한 어떠한
개인정보도 수집·저장·전송하지 않습니다. 회원가입 및 로그인 기능이 없습니다.

## 2. 기기 안에 저장되는 정보

아래 정보는 **사용자의 기기 내부 저장 공간에만** 보관되며, 개발자를 포함한 누구도
접근할 수 없습니다.

| 항목 | 저장 위치 | 목적 |
|---|---|---|
| 쿠폰 정보 (브랜드, 상품명, 유효기간, 금액, 메모) | 앱 내부 데이터베이스 | 쿠폰 관리 |
| 쿠폰 바코드·교환권 번호 | 앱 내부 데이터베이스 | 매장에서 사용 |
| 쿠폰 이미지 | 앱 전용 저장 영역 | 쿠폰 확인 |
| 사용 내역 (금액, 시각, 사용처) | 앱 내부 데이터베이스 | 잔액 계산 |
| 앱 설정 | 기기 설정 저장소 | 사용자 환경 유지 |

앱을 삭제하면 위 정보는 기기에서 함께 삭제됩니다.

## 3. 기기 권한

| 권한 | 사용 목적 | 거부 시 |
|---|---|---|
| 사진 / 저장소 읽기 | 갤러리에 저장된 기프티콘 이미지를 **기기 안에서** 분석해 정보를 자동 입력 | 자동 인식을 쓸 수 없고, 직접 입력으로 등록 |
| 알림 | 유효기간 만료 전 알림 발송 | 만료 알림을 받을 수 없음 |

사진 권한은 **읽기 전용**입니다. 앱이 사진을 수정하거나 삭제하지 않으며, 갤러리에
새 파일을 만들지도 않습니다.

## 4. 이미지 인식 처리 방식

기프티콘 이미지의 문자·바코드 인식은 Google ML Kit의 **온디바이스(on-device)** 모델로
기기 안에서 수행됩니다. 이미지가 네트워크로 전송되지 않으며 인터넷 연결 없이도
동작합니다.


## 5. 제3자 제공 및 광고

- 개인정보를 제3자에게 제공하지 않습니다. 제공할 정보가 존재하지 않습니다.
- 광고를 표시하지 않으며 광고 SDK를 포함하지 않습니다.
- 사용 행태를 분석하는 트래킹 SDK를 포함하지 않습니다.

## 6. 아동의 개인정보

이 앱은 개인정보를 수집하지 않으므로 아동으로부터 정보를 수집하는 일도 없습니다.
만 14세 미만 아동도 안전하게 사용할 수 있습니다.

## 7. 이용자의 권리

수집된 개인정보가 없으므로 열람·정정·삭제를 요청할 대상이 없습니다.
기기에 저장된 데이터는 사용자가 직접 앱 내에서 삭제하거나 앱을 삭제해 전부 지울 수 있습니다.

## 9. 데이터 보안

- 쿠폰 이미지는 다른 앱이 접근할 수 없는 앱 전용 저장 영역에 보관됩니다.
- 서버에 데이터를 두지 않으므로 서버 침해로 인한 유출 위험이 없습니다.

## 10. 방침 변경

본 방침이 변경되면 앱 업데이트와 함께 본 페이지에 게시하고 시행일을 갱신합니다.
데이터 처리 방식이 실질적으로 바뀌는 경우 앱 내에서 별도로 안내합니다.
