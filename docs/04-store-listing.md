## 전체 설명

```
카톡으로 받은 기프티콘, 캡처만 해두고 잊고 계신가요?
쿠폰다이어리는 갤러리에 잠들어 있는 기프티콘을 자동으로 찾아내서, 만료되기 전에 반드시 쓰게 만드는 앱입니다.


■ 갤러리에서 한 번에 찾기

최근 사진을 훑어 기프티콘으로 보이는 이미지를 자동으로 골라냅니다.
브랜드, 상품명, 유효기간, 바코드까지 읽어서 채워드리니 확인하고 등록만 하면 됩니다.


■ 만료 전에 반드시 알려드립니다

유효기간 30일 · 7일 · 3일 · 하루 전, 저녁 7시에 알림이 갑니다.
같은 날 여러 장이 만료되면 하나로 묶어 보내니 알림이 쏟아지지 않습니다.


■ 금액권 잔액이 자동으로 계산됩니다

스타벅스 3만원권처럼 나눠 쓰는 금액권도 제대로 관리합니다.
사용 화면에서 나올 때 얼마 썼는지만 알려주시면 잔액이 자동으로 차감되고, 사용 내역이 쌓입니다.
"이거 썼던가?" 하고 헷갈릴 일이 없습니다.


■ 매장에서 바로 보여주기만 하면 됩니다

사용 화면을 열면 화면 밝기가 자동으로 최대가 되고 바코드가 크게 표시됩니다.
계산대 앞에서 설정을 뒤질 필요가 없습니다.


■ 선물하기

안 쓸 것 같은 쿠폰은 카톡이나 문자로 바로 선물할 수 있습니다.
보낸 쿠폰은 선물함으로 옮겨져 내 보관함이 깔끔하게 유지됩니다.


■ 사진은 폰 밖으로 나가지 않습니다

인식, 저장, 알림 모두 기기 안에서 처리됩니다.
쿠폰 이미지와 바코드 번호를 서버로 보내지 않습니다. 회원가입도, 로그인도 없습니다.
서비스가 종료되어도 내 폰 안의 쿠폰은 그대로 남습니다.


■ 광고가 없습니다

무료 기능에도 광고를 넣지 않습니다.
사용 기록을 수집하거나 추적하지 않습니다.


― 이런 분께 권합니다 ―
· 카톡 선물을 자주 받는데 관리가 안 되는 분
· 기프티콘을 못 쓰고 만료시킨 경험이 있는 분
· 금액권 잔액이 얼마 남았는지 매번 헷갈리는 분
· 광고 없고 단순한 관리 앱을 찾는 분


본 앱은 언급된 각 브랜드와 제휴 관계가 없으며, 쿠폰의 구매·판매·현금화 기능을 제공하지 않습니다.
```

## 스크린샷 계획

6.9" / 6.5" (iOS), 폰 (Android) 각 5장. 상단에 한 줄 카피를 얹는다.

| # | 화면 | 카피 |
|---|---|---|
| 1 | 보관함 (만료 임박 배너 보이게) | 만료 전에 꼭 쓰게 해드립니다 |
| 2 | 갤러리 스캔 결과 목록 | 갤러리 속 기프티콘, 앱이 알아서 찾아요 |
| 3 | 금액권 상세 (잔액 + 사용 내역) | 금액권 잔액이 자동으로 계산됩니다 |
| 4 | 사용 화면 (바코드) | 계산대에선 보여주기만 하면 끝 |
| 5 | 설정 (온디바이스 안내) | 사진은 폰 밖으로 나가지 않습니다 |

주의: 스크린샷에 **실제 브랜드 로고를 넣지 않는다.** 데모 데이터의 브랜드명 텍스트만
노출한다 (상표 리스크, [`03-release.md`](03-release.md) 8절).

## 심사 노트 (App Review Notes)

```
계정 없이 모든 기능을 사용할 수 있습니다. 로그인이 없습니다.

핵심 기능:
1. 갤러리 사진에서 온디바이스 OCR(ML Kit)로 기프티콘 정보를 자동 추출
2. 금액권 부분 사용 시 잔액 자동 차감 및 사용 이력 관리
3. 유효기간 만료 전 로컬 알림 (D-30/7/3/1)
4. 바코드 표시 시 화면 밝기 자동 조절

기능 확인 방법:
- 첨부한 샘플 기프티콘 이미지를 기기 사진첩에 저장한 뒤
  [쿠폰 등록] > [갤러리에서 한 번에 찾기]를 실행하면 자동 인식이 동작합니다.
- 이미지 없이 확인하시려면 [쿠폰 등록] > [직접 입력]으로 등록 후
  상세 화면에서 [사용하기]를 눌러 바코드 표시를 확인하실 수 있습니다.

데이터 처리:
모든 데이터는 기기 내부에만 저장되며 네트워크로 전송하지 않습니다.
서버가 없고, 분석/광고 SDK를 포함하지 않습니다.
```
