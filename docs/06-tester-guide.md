# 체험판 테스터 안내

**쿠폰다이어리** 웹 체험판을 봐주셔서 감사합니다. 15분이면 충분합니다.

---

## 시작하기

폰 브라우저에서 아래 주소를 엽니다.

```
https://jaythealpha.github.io/coupon-diary-web/
```

iPhone은 Safari에서 **공유 → 홈 화면에 추가**, Android는 Chrome에서 **메뉴 → 홈 화면에 추가**를 하면
앱처럼 전체 화면으로 열립니다. 그 상태로 봐주시는 게 실제 감각에 가깝습니다.

처음 열면 보관함이 비어 있습니다. 화면 안내를 따라 직접 한 장 넣어보시는 것이 첫 단계입니다.

---

## 먼저 알아두실 것

이건 **개발 중인 웹 체험판**입니다. 실제 앱에서만 되는 것들이 있습니다.

| 웹에서 되는 것 | 웹에서 안 되는 것 (실제 앱 전용) |
|---|---|
| 쿠폰 등록·수정·삭제 | 사진에서 자동 인식(OCR) |
| 보관함 검색·정렬·필터 | 갤러리 일괄 스캔 |
| 만료 임박 표시, D-day | 만료 푸시 알림 |
| 금액권 잔액 차감·사용 내역 | 만료 알림 탭 → 쿠폰 바로 열기 |
| 바코드 표시 (번호 입력 시) | 화면 밝기 자동 최대 |
| 선물하기 흐름 | 백업 파일 저장 |

**입력한 데이터는 그 브라우저 안에만 저장됩니다.** 서버로 가지 않고, 다른 기기와도 공유되지 않습니다.
그래도 실제 기프티콘 바코드 번호는 넣지 말아주세요. 아무 숫자나 넣으셔도 동작합니다.

---

## 이것만 봐주세요 (10분)

순서대로 해보시고, 이상한 지점을 메모해주세요.

### 1. 쿠폰 등록

`쿠폰 등록` → `직접 입력` → 브랜드·상품명 입력 → `등록하기`

- [ ] 브랜드를 비우고 등록하면 무슨 일이 일어나나요? 안내가 이해되나요?
- [ ] 등록 후 어디로 가나요? 기대한 곳인가요?
- [ ] 보관함으로 돌아왔을 때 방금 넣은 쿠폰이 보이나요?

### 2. 금액권 잔액 (이 앱의 핵심입니다)

등록할 때 `금액권`을 고르고 액면가 `30000`을 넣어보세요.

- [ ] 등록 직후 바로 `사용하기`가 눌리나요?
- [ ] `사용 완료`를 누르면 얼마 썼는지 묻나요?
- [ ] `6500`을 넣으면 잔액이 23,500원이 되나요?
- [ ] 잔액보다 큰 금액(예: 99999)을 넣으면 어떻게 되나요?
- [ ] 사용 내역이 쌓이는 게 보이나요?

### 3. 매장에서 쓰는 상황

쿠폰번호에 아무 숫자나(예: `8801234567890`) 넣고 등록한 뒤 `사용하기`를 눌러보세요.

- [ ] 바코드가 충분히 크고 선명한가요?
- [ ] **계산대에서 이 화면을 내밀 수 있겠다는 느낌이 드나요?** 뭐가 부족한가요?
- [ ] 번호가 읽기 편한가요?

### 4. 보관함 훑기

- [ ] 만료 임박 쿠폰이 눈에 띄나요?
- [ ] 검색·필터가 기대대로 동작하나요?
- [ ] 쿠폰이 30장쯤 있다고 상상하면, 원하는 걸 빨리 찾을 수 있을 것 같나요?

## 알려주시면 좋은 것

무엇보다 **"어? 왜 이러지" 했던 순간**이 가장 귀합니다. 사소해 보여도 적어주세요.

1. 헷갈렸거나 멈칫한 지점 (어느 화면, 무엇을 하려다가)
2. 문구 중 어색하거나 이해 안 되는 것
3. 이 기능이 없어서 안 쓸 것 같다 싶은 것
4. 반대로, 이거 하나는 괜찮다 싶은 것
5. 사용 기기 (예: iPhone 15 / Safari, 갤럭시 S24 / Chrome)

### 특히 궁금한 것

- 지금 쓰시는 기프티콘 관리 방법이 있나요? (카톡 선물함, 갤러리, 다른 앱, 안 함)
- 이 앱을 실제로 쓰실 것 같나요? 안 쓴다면 무엇 때문인가요?
- 광고 없이 유료(1회 결제 또는 연 구독)라면 어떠신가요?

정직한 부정 의견이 가장 도움이 됩니다. 예의차려 좋게 말씀해주실 필요 없습니다.

## 문제가 생기면

- **화면이 하얗게만 보임** → 주소 뒤에 `?v=2`를 붙여 새로고침해보세요 (캐시 문제)
- **데이터가 사라짐** → 시크릿 모드이거나 브라우저가 저장소를 비운 경우입니다. 일반 모드로 열어주세요
- **아예 접속이 안 됨** → 알려주세요. 주소가 바뀌었을 수 있습니다
